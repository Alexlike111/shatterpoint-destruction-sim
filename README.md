**«ТОЧКА РАЗЛОМА»** — трёхмерный физический симулятор и инженерно-тактическая игра реалистичного разрушения сооружений на базе **TypeScript + Vite + Three.js (WebGL2) + Rapier3D WASM**.

## Ключевые физические системы

- **Бесшовное 3D-дробление Вороного (Anisotropic Voronoi Fracture)** с точным отсечением выпуклых многогранников и сохранением объёма осколков.
- **Пространственный 6-DOF решатель строительной статики (Эйлер—Бернулли + PCG)** с критерием Ренкина—Мора—Кулона, потерей устойчивости Эйлера и честным отрывом потерявших опору фрагментов (`Multi-Source BFS`).
- **Глубоко различная механика 6 материалов**:
  - **Железобетон** — после раскола бетона глыбы удерживаются упруго-пластическими стальными тяжами арматуры (`RebarTether` / `ImpulseJoint`), рвущимися при перегрузке или пережигаемых плазморезаком.
  - **Конструкционная сталь** — образует пластические шарниры изгиба (`PlasticHinge`) и теряет несущую способность при раскалении до `500–850 °C`.
  - **Кирпичная кладка** — разрушается по растворным швам при растяжении и сдвиге.
  - **Дубовый массив** — воспламеняется при `T ≥ 260 °C`, передаёт конвективный пожар вверх по ярусам и обугливается.
  - **Калёное стекло** — мгновенно рассыпается на лучистые осколки от акустического удара и термошока.
  - **Взрывоопасные резервуары (ГСМ)** — вызывают каскадную цепную детонацию и тепловой взрыв `BLEVE` при перегреве.
- **Ударные волны Садовского с 3D raycast-окклюзией** капитальными экранами, вторичный кинетический урон падающих плит и двухосная **3D-сейсмоплатформа** с избирательным частотным резонансом по высоте зданий.
- **Процедурный Web Audio синтезатор** акустики разрушений с фильтрацией в режиме `Bullet-Time`.

## Три игровых режима

1. **Кампания сноса (8 контрактов)** — сметный бюджет, лимитированный боезапас, охраняемые соседние здания (штраф и провал при превышении порога косвенного ущерба), оценка `1–3 ★`, начисление кредитов и сохранение прогресса в `localStorage`.
2. **Свободная Песочница** — 6 архитектурных чертежей (*ЖБ-башня «Монолит»*, *Двухпролётный виадук*, *Кирпичная крепость «Бастион»*, *Промышленный стальной ангар*, *Деревянный склад*, *Каскад «Эффект Домино»*), мульти-спавн на одном полигоне, интерактивный **3D-Конструктор** достройки из 6 материалов и свободный выбор уровня оружия `Ур. 1–5`.
3. **Физическая Лаборатория-полигон** — 4 калиброванных испытательных стенда (*Материалы*, *Баллистика*, *Ударная волна и окклюзия*, *Сейсмоплатформа и резонанс*) и пульт живых физических констант СИ.

## Прогрессия, визуал и управление

- **Мастерская улучшений (`Ур. 1 → Ур. 5`)**: прокачка всех 6 инструментов арсенала (*Кинетическая пушка*, *Направленный заряд C4*, *Фугас*, *Плазморезак*, *Термитная кассета*, *Сейсмоудар*) и покупка пакетов снабжения.
- **Программируемый секвенсор каскадного подрыва C4**: индивидуальная настройка задержки каждого заложенного заряда (`0.00 с .. +2.00 с`) для направленного вала высотных зданий.
- **Инженерный визуализатор и атмосфера**: переключение режимов `PBR`, `Теплокарта напряжений`, `Рентген арматуры`, голографический 3D-прицел на гранях и смена освещения полигона (`День` / `Закат` / `Ночь`).
- **Управление камерой и горячие клавиши**:
  - `ЛКМ` — огонь / закладка C4 / удержание луча плазморезака / установка блока в конструкторе
  - `ПКМ` (перетаскивание) или `СКМ` — орбитальное вращение камеры; одиночный `ПКМ` по заряду — снятие C4
  - `Shift + ПКМ` — панорамирование камеры; `Колесо мыши` — масштаб
  - `1..6` — выбор оружия; `D` — подрыв очереди C4; `Пробел` — пауза; `.` — шаг `1/60 с`; `B` — Bullet-Time; `V` — режим рендера; `R` — сброс полигона; `M` — звук

## Локальный запуск и проверка

```bash
npm install
npm run dev        # сервер разработки (http://localhost:5175)
npm run build      # проверка типов TypeScript и production-сборка в dist/
npm run test:unit  # модульные и интеграционные тесты физического ядра (Vitest)
npm run test:e2e   # сквозные браузерные WebGL2-тесты (Playwright)
```
